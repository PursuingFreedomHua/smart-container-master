# 智能货柜客服小程序 开发流程总结

## 项目概述

将 React + Tailwind CSS 的智能货柜客服 H5 前端，完整转换为微信原生小程序（WXML + WXSS + JS），实现 1:1 像素级还原。

---

## 一、技术栈对比

| 项 | React 原版 | 微信小程序版 |
|----|-----------|-------------|
| 框架 | React 函数式组件 | 微信原生 Page 构造器 |
| 样式 | Tailwind CSS + CSS 变量 | WXSS（原生 CSS） |
| 图标 | Lucide React | Unicode 符号 / Emoji |
| 状态管理 | useState / useEffect | data + setData |
| 路由 | 组件内 switch 切换 | 小程序原生 tabBar |
| 构建 | Vite / Webpack | 微信开发者工具内置 |
| 尺寸单位 | px / rem | rpx（1px = 2rpx） |

## 三、核心转换规则

### 3.1 React 组件 → 小程序 Page

```
React:  export function ChatPage() { ... }
小程序: Page({ data: {}, onLoad() {}, 方法名() {} })
```

### 3.2 状态管理映射

| React | 小程序 |
|-------|--------|
| `const [value, setValue] = useState('')` | `data: { value: '' }` |
| `setValue('new')` | `this.setData({ value: 'new' })` |
| `useEffect(() => {...}, [dep])` | 生命周期：`onLoad` / `onShow` |
| 组件卸载清理 `return () => clearTimer()` | `onUnload()` |

### 3.3 JSX → WXML 语法映射

| React (JSX) | 小程序 (WXML) |
|-------------|---------------|
| `{condition && <div>}` | `<view wx:if="{{condition}}">` |
| `{condition ? <A> : <B>}` | `<block wx:if/wx:else>` |
| `{list.map(item => <div key={id}>)}` | `<view wx:for="{{list}}" wx:key="id">` |
| `onClick={handler}` | `bindtap="handler"` |
| `onChange={(e) => setValue(e.target.value)}` | `bindinput="handler"` |
| `style={{color: 'red'}}` | `style="color: red;"` |
| `className={`base ${active ? 'on' : ''}`}` | `class="base {{active ? 'on' : ''}}"` |

### 3.4 Tailwind CSS → WXSS 映射

| Tailwind 类名 | WXSS 属性 | 说明 |
|--------------|-----------|------|
| `bg-card` | `background-color: #FFFFFF` | 精确 hex |
| `text-text-primary` | `color: #1D2129` | 精确 hex |
| `text-[15px]` | `font-size: 30rpx` | 1px = 2rpx |
| `rounded-xl` | `border-radius: 24rpx` | Tailwind 默认值 × 2 |
| `p-4` | `padding: 32rpx` | 4 × 8rpx |
| `gap-3` | `gap: 24rpx` | 3 × 8rpx |
| `shadow-[0_2px_8px_0_rgba(0,0,0,0.06)]` | `box-shadow: 0 4rpx 16rpx 0 rgba(0,0,0,0.06)` | 完整还原 |
| `bg-gradient-to-br from-[#4E5969] to-[#1D2129]` | `background: linear-gradient(135deg, #4E5969, #1D2129)` | 渐变完整写出 |

## 六、运行步骤

### 6.1 开发环境准备
1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 注册微信小程序账号 → [https://mp.weixin.qq.com](https://mp.weixin.qq.com) → 注册 → 选择"小程序" → 个人主体即可
3. 登录后获取 AppID（`wx` 开头的一串字符）

### 6.2 导入项目
1. 打开微信开发者工具 → 点击"+" → "导入项目"
2. 项目目录选择：`miniprogram/` 文件夹
3. AppID 填入你注册的 AppID（或选择"测试号"）
4. 项目名称：智能货柜客服
5. 点击确定

### 6.3 预览到手机
1. 确保微信开发者工具已登录你的微信
2. 点击工具栏 **"预览"** 按钮
3. 手机微信扫码生成的二维码
4. 手机上即可体验完整功能

## 七、后续对接后端 API

### 7.1 聊天页 —— 接入 `container-kefu` SSE 流式对话

在 `pages/chat/chat.js` 中，将 `handleSendMessage` 方法里的模拟回复替换为：

```javascript
// 模拟客服延迟回复（当前）
this._replyTimer = setTimeout(() => { ... }, 1000);

// 替换为：对接后端 SSE 接口
wx.request({
  url: 'https://你的后端地址/kefu/chat/stream',
  method: 'GET',
  data: { sessionId: this.data.sessionId, message: content },
  enableChunked: true,  // 启用流式传输
  success: (res) => { ... }
});
```

### 7.2 订单页 —— 接入订单查询接口

在 `pages/order/order.js` 中：

```javascript
// 替换 loadOrders() 方法
loadOrders() {
  wx.request({
    url: 'https://你的后端地址/api/orders',
    method: 'GET',
    success: (res) => {
      this.setData({ orders: res.data });
    }
  });
}
```

### 7.3 报修/退款 —— 接入提交接口

```javascript
// 替换模拟提交
wx.request({

  method: 'POST',
  data: {
    issueType: selectedIssue,
    description: description,
    contact: contact,
    cabinetId: cabinetInfo.id
  },
  success: (res) => { ... }

```

### 7.4 需要后端提供的 API 清单

| 接口 | 方法 | 路径 | 用途 |
|------|------|------|------|
| 流式对话 | GET | `/kefu/chat/stream` | SSE 流式 AI 对话 |
| 创建会话 | POST | `/kefu/session/create` | 获取 sessionId |
| 会话历史 | GET | `/kefu/session/history` | 加载历史消息 |

| 提交退款 | POST | `/api/refund/submit` | 提交退款申请 |

## 八、注意事项

1. **尺寸单位**：微信小程序使用 `rpx`（responsive pixel），以 iPhone 6（375px 宽度）为基准，1px = 2rpx
2. **CSS 兼容性**：WXSS 不支持 CSS 的 `gap` 属性在较低版本基础库中可能有兼容问题，建议使用 `margin` 替代方案
3. **Tab 图标**：当前 Tab 使用纯文字，如需图标可准备 81×81px 的 PNG 图片，放入项目并配置 `app.json` 中的 `iconPath` / `selectedIconPath`
4. **网络请求**：正式上线需在小程序后台配置服务器域名白名单（request 合法域名）
5. **真机调试**：手机预览时如遇网络问题，可尝试在开发者工具中开启"不校验合法域名"
6. **版本兼容**：代码兼容微信基础库 2.30.0 及以上版本
